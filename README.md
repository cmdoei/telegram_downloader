# ربات دانلودر تلگرام 🤖

رباتی که هر لینکی را می‌گیرد و محتوایش را می‌فرستد — آماده‌ی استقرار دائمی روی Railway.

## چه کاری می‌کند؟
| نوع لینک | رفتار |
|---|---|
| فایل مستقیم (mp4، mp3، عکس، PDF…) | دانلود و ارسال فایل |
| یوتیوب و سایت‌های ویدیویی | استخراج با yt-dlp و ارسال ویدیو |
| صفحه‌ی وب معمولی | استخراج متن صفحه و ارسال |
| فایل بزرگ‌تر از ۴۹ مگ | پیام خطا (سقف آپلود API ربات تلگرام) |

## راه‌اندازی دائمی روی Railway — بدون نصب هیچ‌چیز روی سیستم خودت

### قدم ۱: ساخت ربات
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده
2. دستور `/newbot` را بزن و اسم و نام کاربری انتخاب کن
3. توکنی که می‌دهد را کپی کن (شبیه `1234567890:AAEh...`)

### قدم ۲: انتشار روی Railway
1. برو به [railway.app](https://railway.app) و با گیت‌هاب لاگین کن (یا اکانت مهمان)
2. **New Project → Deploy from GitHub repo** — اول این پوشه را به یک ریپوی گیت‌هاب آپلود کن (از خود سایت گیت‌هاب می‌توانی فایل‌ها را دستی آپلود کنی)
3. بعد از ساخت سرویس، روی آن بزن → تب **Variables** → متغیر جدید:
   - نام: `BOT_TOKEN`
   - مقدار: توکن BotFather
4. تب **Settings** → **Start Command** را بگذار: `python bot.py`
5. تب **Deployments** → **Deploy** — Railway خودش `requirements.txt` را می‌خواند، پایتون و همه‌ی کتابخانه‌ها را **روی سرور خودش** نصب می‌کند و ربات را روشن نگه می‌دارد

### قدم ۳: تمام ✅
در تلگرام به رباتت پیام بده `/start` و یک لینک بفرست.

## نکته‌ها
- پلن رایگان Railway محدودیت مصرف دارد؛ برای ربات شخصی سبک معمولاً کافی است. اگر تمام شد، پلن Hobby (~۵ دلار) بی‌نهایت است.
- ربات با **Polling** کار می‌کند؛ نه دامنه می‌خواهد نه SSL — فقط توکن.
- استوری‌های خصوصی اینستاگرام یا محتوای نیازمند لاگین را نمی‌تواند بگیرد.
- اگر ویدیوها بزرگ‌اند و ۴۹ مگ کم است، باید نسخه‌ی MTProto (با Telethon و اکانت کاربری) ساخت — بگو تا برایت بسازم.
